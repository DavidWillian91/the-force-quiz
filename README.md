# Star Wars Quiz

Se você é fã de Star Wars, este é o quiz perfeito para testar seus conhecimentos sobre a galáxia! Responda perguntas sobre os filmes, personagens e eventos icônicos da saga e descubra o quanto você está conectado com a Força.

## Funcionalidades
- Perguntas sobre personagens, planetas e acontecimentos de Star Wars.
- Feedback com base no número de respostas corretas.
- Efeitos de digitação para uma experiência mais imersiva.
